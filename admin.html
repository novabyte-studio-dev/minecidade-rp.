COMO PUBLICAR PELO CELULAR

Salvar os valores atualizados

  1. Confira o comprovante no PicPay e confirme o recebimento.
  2. Adicione o valor usando os botões acima, inclusive o de valor livre, ou corrija os números manualmente.
  3. Toque em Copiar atualização.
  4. Toque em Entrar com GitHub e salvar. Faça login com a conta novabyte-studio-dev, se necessário.
  5. No editor do GitHub, apague o conteúdo de data/campanha.json, cole a atualização e toque em Commit changes.
  6. Aguarde a publicação automática do GitHub Pages. O valor público será atualizado após a nova versão entrar no ar.

Se outra pessoa não tiver permissão para editar seu repositório, o GitHub não deixará salvar diretamente.
