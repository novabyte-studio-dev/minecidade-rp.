# 🏙️ MineCidade RP

**Sua vida. Sua cidade. Suas escolhas.**

A **MineCidade RP** é um projeto de servidor de roleplay para Minecraft, planejado para jogadores **Java e Bedrock**. A proposta é uma cidade moderna onde as pessoas possam morar, trabalhar, comprar imóveis, abrir lojas e participar da economia fictícia.

> **Status: em desenvolvimento.** As funcionalidades descritas aqui estão planejadas e ainda não representam recursos prontos para jogar.

## 🎮 Funcionalidades planejadas

- Casas e apartamentos, prefeitura, banco, lojas, posto de gasolina e veículos.
- Terrenos públicos, compra, venda, aluguel, parcelamento e empregos.
- Economia fictícia, dinheiro em espécie, carteiras, caixas eletrônicos e pagamentos simulados.
- **MinePhone**, computadores, notebooks, **MineOS** e navegador fictício **MineBrowser**.
- Rede móvel fictícia, planos de internet e roteadores da **MineNet**.
- Comunicação por proximidade, grupos de rádio e ligações: **ainda sujeitos a testes**.
- Servidor planejado com Purpur, Geyser e Floodgate para Java e Bedrock.

### Kit de boas-vindas (planejado)
Cada novo jogador receberá **R$ 1.000 fictícios**, uma **casa popular alugada por R$ 10/mês**, e o celular básico **Mine Fone A1** (2G, 1 GB de RAM e 2 GB de armazenamento — especificações simuladas no jogo).

## 🛠️ Tecnologias e hospedagem

- **Minecraft:** Purpur + Geyser/Floodgate, com hospedagem planejada no exaroton.
- **Página pública:** HTML/CSS/JavaScript, que pode ser hospedada no GitHub Pages.
- **Confirmação de pagamentos:** uma aplicação Python separada, com painel privado e conferência manual no PicPay.

O **GitHub Pages não executa Python nem recebe comprovantes diretamente**. O envio de comprovantes exige uma hospedagem de backend, HTTPS, banco de dados e armazenamento privado.

## 🔒 Segurança e privacidade

Não enviar para este repositório público senhas, tokens, arquivos `.env` com credenciais, comprovantes Pix, bancos de dados nem dados pessoais dos apoiadores.

Comprovante enviado **não significa pagamento confirmado**. A aprovação e a contabilização das contribuições dependem da conferência real da transação.

## 📌 Transparência

A MineCidade RP é um projeto independente, **não oficial**, sem vínculo com Mojang ou Microsoft. A monetização deverá respeitar as regras do Minecraft. Recebimentos reais e a administração da campanha devem ser acompanhados por um responsável adulto.
